Data Analysis Project for Fast Fashion, Goal is to answer the following:
What materials make up each retailer's product catalog, and how do they differ across brands? 
What share of each brand's polyester is recycled (RPET) vs. virgin (PET)?
Does the average number of distinct materials per product differ significantly by store? (one-way ANOVA)
Does the % composition of polyester, recycled polyester, and cotton differ significantly by store? (one-way ANOVA + Tukey HSD)
Is any regional difference in polyester composition consistent across brands, or does it depend on which brand you're looking at?
Does recycled polyester actually predict a different price than virgin polyester, once you control for which store sold it?
